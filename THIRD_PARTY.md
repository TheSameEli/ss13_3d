# Сторонние компоненты и ресурсы

## BandaStation / SS220 и /tg/station

Основной источник игровых DMI, палитр, parallax, лавы и правил структуры мира: [ss220club/Bandastation](https://github.com/ss220club/Bandastation), происходящий от /tg/station. Ресурсы не созданы этим рендерером. Компилятор классификации читает их из отдельно указанного рабочего дерева.

В upstream README указаны AGPL v3 для современного кода, GPL v3 для старого кода и отдельные исключения. Для assets, включая иконки и звуки, указан CC BY-SA 3.0, если для конкретного ресурса не оговорено иное. Смотрите [upstream README, раздел LICENSE](https://github.com/ss220club/Bandastation#license), исходный LICENSE и индивидуальные уведомления авторов. Этот файл фиксирует происхождение, а не заменяет индивидуальные лицензии ресурсов.

Сгенерированные заголовки содержат производные данные, в том числе сами пиксели. Собранная DLL тоже встраивает часть этих ресурсов. Поэтому бинарный релиз требует сохранения атрибуции/лицензий соответствующих assets и проверки исключений; одной копии AGPL для всех данных недостаточно. Исходный exporter по умолчанию такие файлы не копирует.

## BYOND

DreamSeeker, byondcore.dll и byondwin.dll — сторонние бинарные компоненты. Мод их не распространяет и не меняет на диске. Пользователь устанавливает поддерживаемую версию отдельно. Имена экспортов, RVA и наблюдаемая раскладка структур используются для совместимости с конкретной сборкой и не являются официальным стабильным SDK.

## Авторство проекта

Создатель этого мода — [TheSameEli](https://www.twitch.tv/thesameeli). См. [AUTHORS.md](AUTHORS.md). Это указание относится к проекту мода и не заменяет авторство сторонних ресурсов.

Встроенная музыка и серверное дополнение удалены; текущая сборка не содержит пользовательских аудиофайлов.

## Инструменты

Pillow используется для сборки ресурсов; Python и Visual Studio Build Tools/Windows SDK устанавливаются отдельно. Windows/D3D9/D3DCompiler — системные зависимости. Никаких копий этих инструментов исходный пакет не содержит.
